# Marvin Easy

A very simple mobile ride launcher for Marvin.

## Setup

1. Replace the placeholder addresses in `destinations.js`.
2. Upload `index.html`, `style.css`, `app.js`, and `destinations.js` to the root of this repository.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Open the GitHub Pages address on Marvin's iPhone.
7. In Safari, use **Share → Add to Home Screen**.

To add another destination later, copy one object in `destinations.js` and change its name and address.
